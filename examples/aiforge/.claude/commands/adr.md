# /adr — 新建架构决策记录

快速创建一个新的 ADR（Architecture Decision Record）。

## 使用方式

```
/adr [决策主题]
```

例如：`/adr 多租户数据隔离方案`

## 执行步骤

1. 读取 docs/adr/ 目录，确认下一个编号
2. 按以下模板生成 ADR 文件：`docs/adr/NNN-[kebab-case-title].md`
3. 自动填充日期和作者

## ADR 模板

```markdown
# ADR-NNN: [标题]

**状态**: 草稿 / 已采纳 / 已废弃 / 已替代  
**日期**: YYYY-MM-DD  
**作者**: XXX  
**关联**: [相关文件或模块]

---

## 背景

[描述为什么需要做这个决策，当前面临什么问题或需求]

---

## 决策驱动因素

[列出影响决策的关键因素，如性能、安全、开发效率、维护成本等]

---

## 考虑的方案

### 方案 A: [名称]
**优点**:   
**缺点**: 

### 方案 B: [名称] ✅ 已采纳（如果适用）
**优点**:   
**缺点**: 

---

## 决策

**采纳方案 X，原因：**

[具体说明选择的理由，以及如何处理该方案的缺点]

---

## 结果与验证

- [ ] 验证指标 1
- [ ] 验证指标 2
```

## 注意事项

- ADR 一旦采纳，不要修改内容，如果决策改变，新建一个 ADR 标注"替代 ADR-NNN"
- 状态流转：草稿 → 已采纳 → （已废弃 / 已替代）
