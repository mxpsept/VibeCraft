# /review — 代码审查

对当前修改的文件执行标准化 Code Review。

## 执行步骤

1. **安全检查**（参考 .rules/enterprise.md）
   - 是否有硬编码密钥、密码、Token
   - 是否绕过了鉴权中间件
   - 是否有 SQL 注入风险
   - 日志是否屏蔽了敏感字段

2. **架构检查**（参考 .rules/project.md）
   - 是否遵守分层原则（routers 不写业务逻辑）
   - 模型调用是否经过 services/router.py
   - 是否有跨模块的非法引用

3. **代码质量检查**（参考 .rules/personal.md）
   - 所有函数是否有类型注解
   - 异步 IO 是否正确使用 async/await
   - 错误处理是否完整（无静默失败）
   - 命名是否清晰（无缩写，无魔法数字）

4. **测试检查**
   - 新增 service 层逻辑是否有对应单元测试
   - 边界条件是否覆盖

5. **文档检查**
   - 复杂函数是否有 docstring
   - 重要设计决策是否需要新增 ADR

## 输出格式

```
## Review 结果

### 🔴 必须修改（Blocking）
- ...

### 🟡 建议修改（Suggestion）
- ...

### 🟢 值得保留（Good）
- ...

### 📝 补充建议
- ...
```
