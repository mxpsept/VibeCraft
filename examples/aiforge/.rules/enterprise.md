# Rules: 企业级规范

> 适用范围：所有企业级项目通用。与具体技术栈无关，可跨项目复用。
> 优先级：最高。其他层级的规则不得与本文件冲突。

---

## 安全规范

### 密钥与凭证
```
✅ 所有密钥通过环境变量注入，从不硬编码
✅ .env 文件加入 .gitignore，提供 .env.example
✅ API Key 存储必须加密（AES-256 或 bcrypt hash）
✅ 日志中屏蔽敏感字段（key、password、token、secret）
❌ 不在 URL 参数中传递密钥
❌ 不在前端代码中暴露后端密钥
❌ 不在错误信息中返回内部实现细节
```

### 接口安全
```
✅ 所有 API 必须经过鉴权中间件
✅ 使用 HTTPS（生产环境强制）
✅ 敏感接口加速率限制（Rate Limit）
✅ 输入参数严格校验（Pydantic / Schema 验证）
✅ SQL 操作使用参数化查询，禁止字符串拼接
✅ 文件上传校验类型、大小、内容
❌ 不信任客户端传来的用户 ID / 租户 ID（服务端从 token 解析）
```

### 数据隔离
```
✅ 多租户系统：数据库查询必须带 tenant_id 过滤
✅ 用户只能访问自己租户的数据
✅ 管理员操作需二次确认并记录
✅ 敏感数据字段（个人信息）加密存储
```

## 日志规范

### 必须记录
```
- 所有 API 请求：时间、路径、方法、状态码、耗时
- 鉴权事件：登录、登出、Key 创建/删除/使用
- 模型调用：时间、模型名、来源(local/cloud)、input/output tokens
- 错误事件：完整 stack trace（不对外暴露）
- 管理员操作：操作人、操作内容、操作时间
```

### 日志格式（JSON 结构化）
```json
{
  "timestamp": "2026-06-02T10:00:00Z",
  "level": "INFO",
  "service": "aiforge-gateway",
  "tenant_id": "tenant_xxx",
  "user_id": "user_xxx",
  "event": "model.call",
  "data": {
    "model": "qwen3:9b",
    "backend": "local",
    "input_tokens": 128,
    "output_tokens": 256,
    "latency_ms": 1200
  }
}
```

### 禁止记录
```
❌ 不记录完整的用户对话内容（隐私）
❌ 不记录 API Key 明文
❌ 不记录密码
```

## 错误处理规范

### 错误响应格式（统一）
```json
{
  "code": "KEY_EXPIRED",
  "message": "API Key 已过期",
  "detail": "Key 于 2026-05-01 失效，请联系管理员重新生成",
  "request_id": "req_xxx"
}
```

### 错误分类
```
4xx 客户端错误: 返回明确的错误码和用户友好信息
5xx 服务端错误: 返回 request_id，内部记录完整 trace，不暴露细节
超时错误: 统一返回 408，前端展示"请求超时，请重试"
限流错误: 返回 429 + Retry-After header
```

## 合规规范

### 数据保留
```
- 操作日志保留 90 天
- 模型调用记录保留 30 天
- 用户行为数据保留 7 天
- 日志定期归档，过期自动清理
```

### 审计要求
```
- 所有数据变更操作必须可追溯
- 删除操作采用软删除（is_deleted 标记）
- 批量操作记录操作人和操作时间
- 提供数据导出接口（满足合规审查）
```

---

## 可用性规范

```
- 关键服务接口可用性目标：99.9%
- 核心接口超时设置：10s
- 数据库连接池：最大 20，最小 5
- 缓存穿透防护：空值缓存 60s
- 熔断策略：连续 5 次失败触发，30s 后恢复探测
```
