# AIForge SKILL.md

> 本文件是 AI Agent 生成 UI 代码时的硬性约束。DESIGN.md 定义"看起来像什么"，SKILL.md 定义"必须符合什么规则"。两者配合使用。

---

## Mission

生成企业级 AI 平台 UI：信息密度高、操作路径短、视觉噪音低。
面向工程师和企业决策者，不面向消费者。

---

## 技术约束

```
框架: Vue 3 (Composition API) 或 原生 HTML/CSS
图标: lucide-vue-next 或 lucide 图标库（仅此一种）
图表: Recharts（React 环境）/ Chart.js（原生环境）
CSS变量: 必须使用 DESIGN.md 中定义的 CSS 变量，不允许硬编码颜色
单位: px 或 rem，不使用 em（避免嵌套继承问题）
断点: mobile=375px / tablet=768px / desktop=1280px
```

---

## 组件质量门禁

生成每个组件前，自检以下清单：

### ✅ 必须包含
- [ ] loading 状态（骨架屏或 spinner）
- [ ] 空状态（empty state）
- [ ] 错误状态（error state）
- [ ] hover / focus / active 交互状态
- [ ] 响应式适配（至少 mobile + desktop）
- [ ] aria-label 或语义化 HTML

### ❌ 禁止出现
- [ ] 硬编码颜色值（#xxx 或 rgb()）
- [ ] 内联 style 超过 3 个属性
- [ ] 无 key 的 v-for 循环
- [ ] 未处理的 Promise（无 catch）
- [ ] console.log 遗留在生产代码
- [ ] 超过 300 行的单文件组件（拆分）

## 页面生成规则

### 数据展示页（表格/列表）
```
1. 顶部: 页面标题 + 操作按钮（右对齐）
2. 筛选栏: 搜索框 + 筛选器（折叠在"筛选"按钮后）
3. 数据表格: 含分页、排序、行操作
4. 空状态: 无数据时显示图标+文案+CTA
5. 加载态: Skeleton 表格行（不是整页 loading）
```

### 表单页（创建/编辑）
```
1. 最大宽度 680px，居中
2. 字段分组，每组有小标题
3. 必填项标 *（红色）
4. 实时校验（blur 触发，不是 submit）
5. 底部: 取消（Ghost）+ 保存（Primary），右对齐
```

### 仪表盘页
```
1. 顶部 Metrics Row: 4个核心指标卡片
2. 主图表区（折线/柱状）: 含时间范围选择
3. 次要数据: 表格或饼图
4. 右侧栏: 实时状态 / 最近活动
```

## 文案规则

```
按钮: 动词开头，简短（"创建 Key"，不是"点击这里创建 API Key"）
标题: 名词短语（"API 密钥管理"，不是"管理你的 API 密钥"）
描述: 不超过 2 行，说明"是什么"而非"怎么用"
错误信息: 说明原因 + 给出行动（"Key 已过期，请重新生成"）
空状态: 正面引导（"还没有知识库，创建第一个"）
```

## AIForge 专属组件规范

### ModelBadge（模型来源标识）
```
本地模型: 绿色 badge + "Local" + 模型名
云端模型: 蓝色 badge + "Cloud" + 模型名
显示位置: 对话气泡右下角、请求日志表格
```

### UsageBar（用量进度条）
```
0-60%:   success 色
60-80%:  warning 色
80-95%:  error 色（橙）
95-100%: error 色（红）+ 警告图标
```

### TenantSelector（租户切换器）
```
位置: Topbar 左侧，Logo 右边
样式: Ghost 下拉，显示当前租户名 + chevron
下拉列表: 最多显示 5 个，超出显示"查看全部"
```

### AuditLog（审计日志条目）
```
格式: [时间] [租户] [用户] [操作] [模型] [tokens]
时间: 相对时间（"3分钟前"）+ hover 显示绝对时间
高危操作: 红色左边框高亮
```

## 性能约束

```
首屏: 关键内容 < 1s 可见（骨架屏策略）
列表: 超过 100 条启用虚拟滚动
图表: 数据点超过 500 降采样后渲染
接口: 所有请求加 loading 状态，超时设 10s
```
